    Random output should pass; every result is re-checked by the same analyzer.

    Why generated beats invented

    People pick predictable patterns without noticing. A random 20-character password has no pattern to guess, so the entropy estimate is honest here, unlike for Password123!. Long random passphrases are the easier-to-remember alternative.

    After generating

    • Save it in a password manager, not a note or email.
    • Use it for one account only.
    • Turn on MFA for that account.
    • Treat demo values here as examples; do not reuse them.
